# nova-native-poc

Proof of concept: two Nova components (`nv-button` and `nv-fieldtext`) written in the
Contract language of [Expo Exact](https://github.com/expo/exact), a pre-alpha app runtime.
They are packaged as `@nova-design-system/native`, themed with Nova's colour tokens, and
checked by one portable test file that runs unchanged on the web host and on Exact's
self-painting Rust host.

"Native" here means Exact's platform hosts: real AppKit/UIKit controls on Apple, a
self-painting host on Linux. It does not mean React, Angular, Vue or Blazor components.
Exact generates no framework components, and inside an existing React page its web build
only works cleanly in an iframe. Findings and recommendation: [REPORT.md](REPORT.md).

## Layout

| Path | What |
|---|---|
| `packages/nova-native/index.contract` | `NvButton` and `NvFieldtext` |
| `app.contract` | Demo sign-up form built only from those components |
| `app.test.contract` | 5 portable behaviour tests |
| `app.tamber` | Nova colours, light and dark, generated by `tools/resolve-tokens.ts` |
| `app.ts` | Data sources (none yet) |
| `embed/` | A React page that mounts the web build directly or in an iframe, measured in headless Chromium |
| `shots/` | Screenshots from each host and embedding mode |

`exact.mjs`, `app.json` and `AGENTS.md` were generated by Exact's `exact new`.

## Run

Needs a checkout of Exact next to this folder (`../exact`, tested at `ec183f2a`), Bun 1.4.2
and Rust (Exact's setup installs what is missing).

```bash
git clone https://github.com/expo/exact ../exact
git -C ../exact checkout ec183f2a
bun ../exact/scripts/exact.mjs setup
bun install
```

```bash
bun exact.mjs web                                 # dev loop, prints its URL
bun exact.mjs test web                            # the 5 tests on the web host
bun exact.mjs linux && bun exact.mjs test linux   # the same tests on the painted host
```

Embedding check (reuses Exact's Playwright; set `CHROME` to a Chromium binary if the
headless shell path in `embed/check.ts` does not exist on your machine):

```bash
cd embed && bun install
ln -s "$(cd ../../exact && pwd)/node_modules/playwright-core" node_modules/playwright-core
HOST_PATH=/ bun run check
```

Regenerate the theme from a built `nova-design-system` checkout next to this folder:

```bash
FORMAT=tamber bun tools/resolve-tokens.ts ../nova-design-system/packages/base/dist/css/spark.css \
  --components-button-high --components-button-medium --components-button-destructive-high \
  --components-form-field --components-form-text --color-focus-brand > app.tamber
```

macOS and iOS hosts need Xcode 27.1; they were not run (see REPORT.md).
